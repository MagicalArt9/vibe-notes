用 GitHub Pages 把網頁公開

部署｜2026-11-16

重點先看

GitHub Pages 是 GitHub 提供的免費網頁空間。只要專案裡有 index.html，打開設定就能得到一個公開網址。

五個步驟

  1. 在 GitHub 建立一個新的 Repository（設成 Public）。
  2. 把專案檔案上傳，index.html 要放在最外層。
  3. 進入 Settings → Pages。
  4. Source 選 Deploy from a branch，Branch 選 main、資料夾選 / (root)，按 Save。
  5. 等 1～2 分鐘，網址會出現在頁面上方。
小提醒：網址格式是 https://帳號.github.io/專案名稱/。如果打開是 404，通常是還在部署中，稍等一下再重新整理。

之後更新網站

修改檔案後再上傳（commit）一次，GitHub Pages 會自動更新，不用重新設定。

一句話總結

有 index.html、打開 Pages、等一下，網站就上線了。
